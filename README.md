# 📚 Indian Books Data Explorer

A Python-based data collection and analysis project that collects book information using the Open Library API, cleans and analyzes the dataset, and presents insights through an interactive Streamlit dashboard.

## 🚀 Features

- Collect book data using Python and the Open Library API
- Clean missing and duplicate records using Pandas
- Analyze authors, languages, and publication years
- Visualize language distribution using Matplotlib
- Search and filter books through a Streamlit dashboard
- Download filtered results as a CSV file

## 🛠️ Tech Stack

- Python
- Requests
- Pandas
- Matplotlib
- Streamlit
- CSV
- Open Library API

## 📁 Project Files

- `main.py` — Collects book data
- `clean_data.py` — Cleans the dataset
- `analyze_data.py` — Performs data analysis
- `visualize_data.py` — Creates charts
- `app.py` — Runs the interactive dashboard
- `requirements.txt` — Lists required Python libraries

## ⚙️ How to Run

1. Clone or download this repository.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Collect the data:

   ```bash
   python main.py
   ```

4. Clean the data:

   ```bash
   python clean_data.py
   ```

5. Run the analysis:

   ```bash
   python analyze_data.py
   ```

6. Generate the chart:

   ```bash
   python visualize_data.py
   ```

7. Launch the dashboard:

   ```bash
   python -m streamlit run app.py
   ```

## 📊 Data Source

Open Library Search API.

Note: The results depend on the search query and may include books that are not exclusively by Indian authors.
